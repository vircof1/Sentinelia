# Logic gate SVG assets

Estos iconos se sirven como assets locales del portal. No dependen de CDN ni de llamadas externas en runtime.

## Origen

- `and-ansi.svg`: Wikimedia Commons, `AND ANSI.svg`, dominio público. Fuente: <https://commons.wikimedia.org/wiki/File:AND_ANSI.svg>
- `or-ansi.svg`: Wikimedia Commons, `OR ANSI.svg`, dominio público. Fuente: <https://commons.wikimedia.org/wiki/File:OR_ANSI.svg>
- `not-ansi.svg`: Wikimedia Commons, `NOT ANSI.svg`, dominio público. Fuente: <https://commons.wikimedia.org/wiki/File:NOT_ANSI.svg>

## Uso

Se utilizan en el editor visual de monitores lógicos para representar puertas ANSI reales dentro del canvas de comportamiento.
